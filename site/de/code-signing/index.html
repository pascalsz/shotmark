Was signiert wird

ShotMarks eigene Programmdateien (ShotMark.exe und die ShotMark-Bibliotheken) und das Setup ShotMark.App-win-Setup.exe. Fremde Bestandteile werden so ausgeliefert, wie ihre Hersteller sie veröffentlichen: Die .NET-Laufzeitdateien sind von Microsoft signiert, die Update-Komponente Velopack wird unverändert mitgeliefert.

Die Signatur wird gerade eingerichtet: Versionen werden signiert, sobald die SignPath Foundation das Projekt freigegeben hat. Bis dahin ist das Setup unsigniert, und Windows SmartScreen zeigt beim ersten Start eine Warnung.

Wie eine Version entsteht

  • Jede Version wird automatisch von GitHub Actions aus dem öffentlichen Repository github.com/pascalsz/shotmark gebaut, sobald ein Versions-Tag gepusht wird.
  • Vor dem Packen laufen die Tests. Signaturanfragen stellt dieser Build, und jede Version muss von Hand freigegeben werden.
  • Die fertigen Dateien erscheinen als GitHub-Release. Installierte Versionen aktualisieren sich von dort selbst.

Datenschutz

ShotMark überträgt keine Informationen über dich oder deine Aufnahmen an andere Systeme im Netz. Der einzige Netzwerkzugriff ist die automatische Update-Prüfung: Die App lädt die Versionsliste und, wenn es eine neuere Version gibt, das Update-Paket von GitHub (github.com/pascalsz/shotmark/releases). Das erklärt ShotMark beim ersten Start, und es lässt sich unter Einstellungen → Automatisch nach Updates suchen abschalten. Für diese Downloads gilt die Datenschutzerklärung von GitHub.

Aufnahmen landen nur in dem Ordner, den du wählst. Synchronisiert ein Dienst wie Dropbox oder OneDrive diesen Ordner, gilt dessen Datenschutzerklärung.

Signatur prüfen

Rechtsklick auf ShotMark.App-win-Setup.exe → Eigenschaften → Digitale Signaturen. Bei einer signierten Version steht dort „SignPath Foundation“ als Signierer.
