Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

ShotMark's own program files (ShotMark.exe and the ShotMark libraries) and the installer ShotMark.App-win-Setup.exe. Third-party components are shipped as published by their vendors: the .NET runtime files are signed by Microsoft, the update engine Velopack is shipped unchanged.

Signing is being set up: releases are signed once the SignPath Foundation has approved the project. Until then the setup is unsigned and Windows SmartScreen shows a warning on the first start.

How a release is built

  • Every release is built automatically by GitHub Actions from the public repository github.com/pascalsz/shotmark when a version tag is pushed.
  • The tests run before anything is packed. Signing requests are submitted by that build and must be approved manually for every release.
  • The finished files are published as a GitHub release. Installed copies update themselves from there.

Privacy

ShotMark does not send any information about you or your captures to other networked systems. The only network access is the automatic update check: the app downloads the release list and, if there is a newer version, the update package from GitHub (github.com/pascalsz/shotmark/releases). This is explained on first start and can be switched off under Settings → Check for updates automatically. GitHub's own privacy statement applies to these downloads.

Captures are only saved to the folder you choose. If that folder is synchronised by a service such as Dropbox or OneDrive, that service's privacy policy applies.

Uninstall

Windows Settings → Apps → Installed apps → ShotMark → Uninstall. Your captures stay in their folder. Settings and the local log are kept in %APPDATA%\ShotMark and %LOCALAPPDATA%\ShotMark; delete those folders if you want them gone too.

Check a signature

Right-click ShotMark.App-win-Setup.exe → Properties → Digital Signatures. A signed release shows “SignPath Foundation” as the signer.
